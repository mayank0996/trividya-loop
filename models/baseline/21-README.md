# Assumed 3D baseline

This model is a reconstructed concept envelope for discussion and simulation setup. It is not a scan of the physical mockup and is not a validated mechanical, vacuum, levitation, vehicle or clinical design. Dimensions and mass values are assumptions listed in `spec.json`; `[MEASURE]` items remain open.

- `Trividya-Loop-baseline.stl`: merged geometry
- `Trividya-Loop-baseline.obj` + `.mtl`: grouped geometry and materials
- `renders/`: visually checked previews
- `spec.csv` and `spec.json`: assumptions and open measurements

Units are millimetres unless the specification says otherwise.
